ابن السوامي — ملفات الموقع

الملفات:
- index.html: الصفحة الرئيسية.
- style.css: التصميم والألوان والتجاوب مع الجوال والكمبيوتر.
- script.js: تغيير اللغة، اتجاه الصفحة، ونافذة اختيار التواصل.

طريقة الرفع:
1. فك ضغط ملف ibn-alsawami-site.zip.
2. ارفع الملفات الثلاثة الموجودة داخل المجلد مباشرة إلى public_html.
3. تأكد أن index.html موجود مباشرة داخل public_html وليس داخل مجلد فرعي.
4. افتح رابط نطاقك.

ملاحظات:
- رابط تيليجرام يفتح محادثة zzuto مع نص يتضمن اسم الخدمة.
- واتساب وسناب شات والبوت تفتح الروابط المحددة في مواصفات المشروع.
- تغيير اللغة يعمل محلياً ولا يحتاج قاعدة بيانات أو إعدادات خادم.
- الموقع واجهة تعريف وتواصل فقط، ولا ينفذ خدمات استرجاع الحسابات بنفسه.
